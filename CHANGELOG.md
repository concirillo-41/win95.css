# Changelog

## 0.1.0 (October 2026)

First release.

- One stylesheet, `dist/win95.css`, scoped to `.w95`: windows, menus, toolbars, status bars, buttons,
  every form control, group boxes, tabs, list, details, tree and icon views, progress bars, tooltips,
  message boxes, a WordPad page, scrollbars, the desktop, taskbar and Start menu.
- W95 Sans, an original pixel font (capitals 8px, x-height 6px, regular and bold, 3 KB each).
- 16 original 16×16 icons.
- Five colour schemes from `data-scheme`: Windows Standard, Desert, Rainy Day, Eggplant and
  High Contrast Black.
- `dist/win95.js`, an optional window manager: open, focus, drag, resize, minimize, maximize and close;
  taskbar buttons; Start menu and cascading submenus; right-click menus with long-press on touch and
  Shift+F10 on keyboards; modal dialogs that flash when you click past them; tabs; a clock.
- The 1996 web layer: tiled paper, hit counter, under construction tape, ticker, NEW! badge, blink.
- TypeScript types for the `W95` global and its events.
