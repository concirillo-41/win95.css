README.TXT - Notepad 
WIN95.CSS                                README.TXT
==================================================

Version 0.1.0 (4.00.950 in spirit).
A Windows 95 interface kit for the web. One
stylesheet, one optional script, no frameworks.


SETUP
-----
<link rel="stylesheet" href="dist/win95.css">
<script src="dist/win95.js" defer></script>

npm i win95.css, or straight from a CDN:
https://cdn.jsdelivr.net/npm/win95.css/dist/win95.css

<body class="w95">


A WINDOW
--------
<section class="w95-window" id="readme"
         data-icon="notepad" data-w="480" data-h="360">
  <div class="w95-titlebar">
    <span class="w95-ico-notepad"></span>
    <span class="w95-title">README.TXT - Notepad</span>
    <div class="w95-controls">
      <button data-action="minimize"></button>
      <button data-action="maximize"></button>
      <button data-action="close"></button>
    </div>
  </div>
  <div class="w95-body">...</div>
  <span class="w95-grip"></span>
</section>

Anything with data-open="readme" opens it.
data-modal blocks the desktop until it closes.
Add #readme to the URL to open it on arrival.
data-h="auto" sizes a dialog to its content.
data-center centers it.

KNOWN ISSUES
------------
- Font smoothing is off on purpose.
- Will not run in 4 MB of RAM. Neither will
  anything else.
- Phones open every window maximized. This is
  the one place we improved on the original.


THE FONT
--------
W95 Sans, drawn for this kit on a pixel grid:
caps 8px, x-height 6px, 3 KB per weight.
Set --w95-font to use something else.

CREDITS
-------
Font and icons drawn by hand, one pixel at a
time. 98.css showed the way.
